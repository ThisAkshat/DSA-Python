## 23. Quick Sort

### 1. What it does

* Quick Sort arranges elements in ascending or descending order.
* It selects one element called the **pivot**.
* It places smaller elements on one side and larger elements on the other.
* It repeats the process for both sides.
* It uses the **Divide and Conquer** technique.

### 2. Diagram

Sort `[6, 3, 8, 2, 5]`.

Choose `5` as the pivot.

```text
        [6, 3, 8, 2, 5]
                 ↑
               Pivot
```

Place smaller elements on the left and larger elements on the right.

```text
       [3, 2]  [5]  [6, 8]
          ↓            ↓
        [2, 3]        [6, 8]
```

Final sorted array:

```text
[2, 3, 5, 6, 8]
```

### 3. Unique Point

* Quick Sort's average time complexity is **O(n log n)**, but its worst case is **O(n²)**.
* Choosing a good pivot helps avoid poor performance.
* Randomised Quick Sort chooses a random pivot to reduce the chance of repeatedly getting bad partitions.
* Standard in-place Quick Sort is usually not stable, meaning equal elements may change their relative order.
* Unlike Merge Sort, Quick Sort typically needs less extra array memory, although recursion still uses stack space.

### 4. Main Purpose

* To sort data efficiently in typical situations.
* To divide an array into smaller parts using a pivot.
* It is often chosen for in-memory sorting because of its practical performance.
* **Remember:** Merge Sort guarantees `O(n log n)` time; standard Quick Sort does not.
