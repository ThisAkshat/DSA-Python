## 16. Difference Array

### 1. What does it do?

* A Difference Array helps you update a **range of elements quickly**.
* Instead of updating every element in a range, you update only two positions.
* After all updates, calculate the actual values using a running sum.
* It is useful when many range updates are required.

### 2. Diagram

Suppose the array is `[0, 0, 0, 0, 0]`.

Add `+3` from index `1` to index `3`.

**Difference Array update:** Add `+3` at index `1` and `-3` at index `4`.

```text
Original:    [0,  0,  0,  0,  0]
Difference:  [0, +3,  0,  0, -3]
                 ↓
Final:       [0,  3,  3,  3,  0]
```

### 3. Python-specific point

Python can create a difference array easily using:

```python
diff = [0] * (len(arr) + 1)
```

For a range update from index `left` to `right`:

```python
diff[left] += value
diff[right + 1] -= value
```

### 4. Main purpose

* **Use it when many range updates are needed.**
* Updating each element individually can take `O(n)` per update.
* A difference array makes each update `O(1)`.
* After all updates, one pass of `O(n)` reconstructs the final array.
