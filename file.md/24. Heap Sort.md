## 24. Heap Sort

### 1. What it does

* Heap Sort arranges elements in ascending or descending order.
* It uses a data structure called a **Heap**.
* For ascending order, it builds a Max Heap, where the largest element stays at the top.
* It swaps the largest element with the last unsorted element.
* It repeats until the array is sorted.

### 2. Diagram

Sort `[4, 10, 3, 5, 1]` in ascending order.

**Step 1: Build a Max Heap**

```text
          10
         /  \
        5    3
       / \
      4   1
```

The largest element, `10`, is at the top.

**Step 2: Move the largest element to the end.**

```text
Before: [10, 5, 3, 4, 1]
After:  [5, 4, 3, 1 | 10]
```

Repeat this process with the remaining unsorted elements.

**Final sorted array:**

```text
[1, 3, 4, 5, 10]
```

### 3. Unique Point

* Heap Sort guarantees **O(n log n)** time complexity, even in the worst case.
* Building a heap takes **O(n)** time, not `O(n log n)`.
* Heap Sort is an in-place sorting algorithm, requiring **O(1)** auxiliary space with an iterative implementation.
* Unlike Merge Sort, it does not need another array to store merged results.
* However, standard Heap Sort is **not stable**.

### 4. Main Purpose

* To sort data with guaranteed `O(n log n)` time.
* To use a heap to repeatedly access the largest or smallest element.
* To sort an array without requiring an additional array.
* It is useful when predictable performance and low extra memory usage are important.
