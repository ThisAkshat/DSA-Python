## 21. Insertion Sort

### 1. What it does

* Insertion Sort arranges elements in ascending or descending order.
* It takes one element at a time and places it in the correct position.
* It works like arranging playing cards in your hand.
* It compares the current element with previous elements and shifts larger elements to the right.
* It repeats until the entire array is sorted.

### 2. Diagram

Sort `[5, 3, 8, 1]` in ascending order.

```text
Start:       [5, 3, 8, 1]

Take 3:      [3, 5, 8, 1]

Take 8:      [3, 5, 8, 1]

Take 1:      [1, 3, 5, 8]
```

**Result:** `[1, 3, 5, 8]`

### 3. Unique Point

* Insertion Sort is an **adaptive sorting algorithm**.
* This means it performs well when the array is already sorted or nearly sorted.
* Its best-case time complexity is `O(n)` when the array is already sorted.
* Unlike Selection Sort, Insertion Sort is **stable**: equal elements keep their original relative order.
* It is often useful for small arrays and is used as part of some advanced sorting implementations.

### 4. Main Purpose

* To sort small or nearly sorted arrays efficiently.
* To insert each element into its correct position.
* Average and worst-case time complexity: `O(n²)`.
* Space complexity: `O(1)` because it sorts the array in place.
