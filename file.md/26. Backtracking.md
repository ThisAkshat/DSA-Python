## 26. Backtracking

### 1. What it does

* Backtracking tries different possible solutions to solve a problem.
* It makes one choice at a time.
* If a choice leads to an invalid solution, it goes back and tries another choice.
* It follows the idea: **Choose → Explore → Undo**.
* Common examples include Sudoku, maze solving and generating combinations.

### 2. Diagram

**Example:** Find a path through a maze.

```text
START
  |
  v
Choose Path A
  |
  v
Dead End ❌
  |
  v
Go Back
  |
  v
Choose Path B
  |
  v
  GOAL ✅
```

Backtracking does not stop at the first wrong choice. It returns to an earlier point and explores another possibility.

### 3. Unique Point

* Backtracking often uses **Depth-First Search (DFS)** to explore possibilities.
* It can use pruning to stop exploring a path as soon as that path cannot produce a valid solution.
* Pruning can save a huge amount of time, but the worst-case time complexity may still be exponential.
* Unlike ordinary recursion, backtracking usually involves undoing a choice before trying another one.

### 4. Main Purpose

* To find valid solutions among many possible choices.
* To solve problems where one choice affects the next.
* Common applications include Sudoku, N-Queens, maze paths and permutations.
* **Remember:** Recursion is a technique; backtracking is a problem-solving approach that often uses recursion.
