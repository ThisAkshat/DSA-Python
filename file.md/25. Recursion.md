## 25. Recursion

### 1. What it does

* Recursion is a technique where a function calls itself.
* It breaks a big problem into smaller versions of the same problem.
* Every recursive function needs a **base case** to stop.
* Without a proper base case, recursion can continue until Python raises a `RecursionError`.
* Example: calculating the factorial of a number.

### 2. Diagram

Find `factorial(4)`.

**Rule:** `4! = 4 × 3 × 2 × 1 = 24`

The function calls itself with smaller numbers:

```text
factorial(4)
     |
4 × factorial(3)
        |
     3 × factorial(2)
            |
         2 × factorial(1)
                |
                1  ← Base case
```

Now the answers return upward:

```text
factorial(1) = 1
factorial(2) = 2 × 1 = 2
factorial(3) = 3 × 2 = 6
factorial(4) = 4 × 6 = 24
```

**Final answer: `24`**

### 3. Unique Point

* Every recursive call creates a new **stack frame** that stores information about that call.
* These frames stay on the call stack until the calls return.
* Python does not automatically optimise tail recursion, unlike some programming languages.
* Deep recursion can cause a `RecursionError`, even when the logic is correct.
* Sometimes, an iterative loop is more memory-efficient than recursion.

### 4. Main Purpose

* To solve problems that can be divided into smaller versions of themselves.
* Common uses include tree traversal, graph algorithms, backtracking and divide-and-conquer algorithms.
* Recursion can make complex problems easier to express.
* Always identify the **base case** and the **recursive case** before writing the function.
