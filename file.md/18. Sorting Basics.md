## 18. Sorting Basics

### 1. What it does

* Sorting means arranging data in a specific order.
* **Ascending:** Smallest to largest.
* **Descending:** Largest to smallest.
* Example: `[5, 2, 8, 1]` becomes `[1, 2, 5, 8]`.
* Common sorting algorithms include Bubble Sort, Selection Sort, Merge Sort and Quick Sort.

### 2. Diagram

**Ascending order:**

```text
Before:
[5, 2, 8, 1]

       Sorting
          ↓

After:
[1, 2, 5, 8]
```

### 3. Unique Python Point

* Python has a built-in sorting algorithm called **Timsort**.
* `list.sort()` sorts the original list.
* `sorted()` creates and returns a new sorted list.
* Python sorting is stable, meaning equal elements keep their original relative order.

```python
numbers = [5, 2, 8, 1]

print(sorted(numbers))
print(numbers.sort())
print(numbers)
```

Output:

```text
[1, 2, 5, 8]
None
[1, 2, 5, 8]
```

**Interview point:** `list.sort()` returns `None` because it modifies the original list.

### 4. Main Purpose

* To arrange data for easier searching and processing.
* To make comparisons and data analysis easier.
* Sorting can help algorithms like Binary Search work correctly.
* Different sorting algorithms have different time and space complexities.
