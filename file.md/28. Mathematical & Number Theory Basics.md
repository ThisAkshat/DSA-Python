## 28. Mathematical / Number Theory Basics

### 1. What it does

* Mathematical algorithms solve problems using numbers and mathematical rules.
* Number Theory focuses on properties of integers.
* Common topics include prime numbers, factors, GCD, LCM and divisibility.
* These concepts help solve many DSA problems.

### 2. Diagram

**Example: Find the GCD of 12 and 18.**

GCD means the greatest number that divides both numbers exactly.

```text
Factors of 12: 1, 2, 3, 4, 6, 12

Factors of 18: 1, 2, 3, 6, 9, 18

Common factors: 1, 2, 3, 6

GCD = 6
```

### 3. Unique Point

* The **Euclidean Algorithm** finds the GCD without checking every possible factor.
* It uses the rule `GCD(a, b) = GCD(b, a % b)`.
* It runs in `O(log(min(a, b)))` time for positive integers.
* GCD is also useful for finding LCM: `LCM(a, b) = |a × b| / GCD(a, b)`, when both numbers are non-zero.

### 4. Main Purpose

* To solve problems involving prime numbers, factors and divisibility.
* To calculate GCD and LCM efficiently.
* To solve mathematical DSA questions without unnecessary loops.
* These concepts are useful in competitive programming and coding interviews.
