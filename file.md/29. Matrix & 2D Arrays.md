## 29. Matrix / 2D Arrays

### 1. What it does

* A Matrix is a collection of elements arranged in rows and columns.
* A 2D Array stores data in two dimensions.
* Each element is accessed using two indexes: row and column.
* It is useful for representing tables, grids, images and game boards.

### 2. Diagram

Example of a 3 × 3 matrix:

```text
        Column
          0   1   2
        ┌───┬───┬───┐
Row  0  │ 1 │ 2 │ 3 │
        ├───┼───┼───┤
     1  │ 4 │ 5 │ 6 │
        ├───┼───┼───┤
     2  │ 7 │ 8 │ 9 │
        └───┴───┴───┘
```

In Python:

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

To access `5`, use `matrix[1][1]`.

### 3. Unique Point

* Python lists do not provide a traditional fixed-size 2D array; they can store lists of different lengths.
* Creating a matrix with `[[0] * 3] * 3` makes all rows refer to the **same inner list**.
* Changing one row can unexpectedly change every row.
* Use `[[0] * 3 for _ in range(3)]` to create independent rows.
* Matrix traversal usually takes `O(rows × columns)` time.

### 4. Main Purpose

* To store and process data arranged in rows and columns.
* To solve grid-based problems, such as maze traversal.
* To represent images, game boards and mathematical matrices.
* To practise matrix operations and 2D traversal algorithms.
