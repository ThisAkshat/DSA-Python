# 48. Monotonic Queue

## 1. What It Does

1. **Main Job:** A Monotonic Queue finds the maximum or minimum element in each sliding window of an array.
2. **Why It Was Created:** Checking every window separately repeats work. This queue reuses useful information from the previous window.
3. **Time Complexity:** Building and processing the queue takes **O(n)** overall; each element is added and removed at most once.
4. **Different Stages:** Building the initial window takes up to O(k), each window update takes O(1) amortized time, and processing all windows takes O(n). Here, `n` is the array size and `k` is the window size.

## 2. Diagram

**Example:** Find the maximum in every window of size `3`.

```text
Array:  [2, 5, 3, 1, 6]

Window 1: [2, 5, 3]
Queue:    [5, 3]
Maximum:   5

Window 2: [5, 3, 1]
Queue:    [5, 3, 1]
Maximum:   5

Window 3: [3, 1, 6]
Remove:    1, 3, 5
Queue:    [6]
Maximum:   6
```

```text
Final Answer: [5, 5, 6]
```

## 3. Unique Point

1. **Amortized Efficiency:** One update may remove several elements, but across the entire array, each element is added and removed at most once.
2. **Index-Based Tracking:** Storing indices instead of values helps detect elements that have moved outside the current window.
3. **Monotonic Deque:** A double-ended queue allows insertion and removal at both ends, making it suitable for maintaining sliding-window maximums and minimums.
4. **Combined Conditions:** Monotonic queues can help optimize dynamic programming problems, including finding minimum costs over a limited range of previous states.

## 4. Main Purpose

1. **Better Than Repeated Scanning:** A normal scan can take O(nk) time across all windows; a monotonic queue can reduce this to O(n).
2. **Better Than Repeated Sorting:** Sorting each window separately wastes work when consecutive windows overlap. A monotonic queue avoids sorting each window.
3. **Different From Monotonic Stack:** A stack is useful for finding the next greater or smaller element. A queue is useful when the active range moves forward and old elements expire.
4. **Useful for Continuous Updates:** It efficiently maintains the maximum or minimum as a window moves through an array or stream of values.

## 5. Real-World Apps

1. **Stock Market Platforms:** Find the highest or lowest price over a recent period.
2. **Weather Systems:** Track the highest temperature over the last 24 hours.
3. **Website Monitoring:** Identify peak request counts within recent time windows.
4. **Dynamic Programming:** Optimize transitions where the best previous result must come from a fixed range of earlier states.
