## 20. Selection Sort

### 1. What it does

* Selection Sort arranges elements in ascending or descending order.
* It finds the smallest element in the unsorted part.
* It swaps that element with the first unsorted element.
* It repeats until the entire array is sorted.
* Unlike Bubble Sort, it selects the smallest element and places it in its correct position.

### 2. Diagram

Sort `[5, 3, 8, 1]` in ascending order.

**Pass 1:** Find the smallest element (`1`) and swap it with `5`.

```text
[5, 3, 8, 1]
 ↓        ↓
[1, 3, 8, 5]
```

**Pass 2:** Find the smallest element in `[3, 8, 5]` → `3` is already in the correct position.

**Pass 3:** Find the smallest element in `[8, 5]` → swap them.

```text
[1, 3, 5, 8]
```

### 3. Unique Python Point

* Selection Sort performs at most `n - 1` swaps for an array of `n` elements.
* Bubble Sort may perform many swaps, but Selection Sort usually performs fewer.
* However, both have `O(n²)` time complexity in the average and worst cases.

```python
arr = [5, 3, 8, 1]

for i in range(len(arr)):
    min_index = i

    for j in range(i + 1, len(arr)):
        if arr[j] < arr[min_index]:
            min_index = j

    arr[i], arr[min_index] = arr[min_index], arr[i]

print(arr)
```

**Output:** `[1, 3, 5, 8]`

### 4. Main Purpose

* To sort an array by repeatedly selecting the smallest element.
* It is useful for understanding selection and swapping.
* It performs fewer swaps than Bubble Sort in typical cases.
* It is inefficient for large arrays because its time complexity is `O(n²)`.
