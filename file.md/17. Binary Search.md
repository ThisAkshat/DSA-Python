## 17. Binary Search

### 1. What it does

* Binary Search finds a target value in a **sorted array**.
* It checks the middle element first.
* If the target is smaller, it searches the left half.
* If the target is larger, it searches the right half.
* It repeats until the target is found or no elements remain.

### 2. Diagram

Find `60` in this array:

```text
[10, 20, 30, 40, 50, 60, 70]
               ↑
             Middle
```

`40 < 60`, so search the right half.

```text
[50, 60, 70]
     ↑
   Middle
```

`60 == 60` → Target found!

### 3. Unique Python Point

* Binary Search has **O(log n)** time complexity.
* Python's `bisect` module provides built-in functions for binary search on sorted lists.
* `bisect_left(arr, target)` finds the position where the target can be inserted while keeping the list sorted.
* It does not directly return `-1` when the target is absent; you must check whether the target actually exists.

### 4. Main Purpose

* To search sorted data quickly.
* Linear Search checks elements one by one: `O(n)`.
* Binary Search repeatedly removes half of the search area: `O(log n)`.
* **Important:** The array must be sorted for standard Binary Search to work correctly.
