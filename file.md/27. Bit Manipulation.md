# 27. Bit Manipulation

### 1. What it does

Bit Manipulation means working directly with the binary bits (`0` and `1`) of a number.

Example:

```text
Decimal:  5
Binary:   101
```

### 2. Diagram — Important Operations

Hum `5 = 101` aur `3 = 011` use karenge.

| Operation   | Symbol | Example      | Answer    | Rule                       |
| ----------- | ------ | ------------ | --------- | -------------------------- |
| AND         | `&`    | `101 & 011`  | `001` = 1 | Both bits must be 1        |
| OR          | `\|`   | `101 \| 011` | `111` = 7 | At least one bit must be 1 |
| XOR         | `^`    | `101 ^ 011`  | `110` = 6 | Bits must be different     |
| NOT         | `~`    | `~5`         | `-6`      | Flips all bits             |
| Left Shift  | `<<`   | `5 << 1`     | 10        | Shifts bits left           |
| Right Shift | `>>`   | `5 >> 1`     | 2         | Shifts bits right          |

**AND example:**

```text
  101  (5)
& 011  (3)
-----
  001  (1)
```

**XOR example:**

```text
  101  (5)
^ 011  (3)
-----
  110  (6)
```

### 3. Unique Point

* Bit Manipulation can perform certain operations directly on binary bits without using normal arithmetic operations.
* It can **set, clear, toggle, and check individual bits**.
* It can store multiple yes/no values using a single integer through bit flags.
* It is used in **cryptography, network protocols, operating systems, and memory-efficient programming**.
* Bitwise operations are often fast, but they are not always better than normal operations in real-world code.
* Unlike ordinary mathematical operations, bitwise operators work on the binary representation of integers.

### 4. Main Purpose

* Solve specific DSA problems efficiently.
* Check odd/even numbers and powers of 2.
* Find unique numbers using XOR.
* Work with binary flags and bit masks.
