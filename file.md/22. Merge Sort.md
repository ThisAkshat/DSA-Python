## 22. Merge Sort

### 1. What it does

* Merge Sort arranges elements in ascending or descending order.
* It divides the array into smaller parts.
* It keeps dividing until each part contains only one element.
* Then it merges the parts in sorted order.
* It uses the **Divide and Conquer** technique.

### 2. Diagram

Sort `[8, 3, 6, 2]`.

**Step 1: Divide**

```text
        [8, 3, 6, 2]
          /       \
      [8, 3]     [6, 2]
       /  \       /  \
     [8]  [3]   [6]  [2]
```

**Step 2: Merge in sorted order**

```text
      [3, 8]     [2, 6]
          \       /
        [2, 3, 6, 8]
```

Final sorted array: `[2, 3, 6, 8]`

### 3. Unique Point

* Merge Sort guarantees **O(n log n)** time complexity, even in the worst case.
* Unlike Quick Sort, its performance does not depend on choosing a good pivot.
* Standard Merge Sort for arrays usually requires **O(n)** extra space.
* It is a stable sorting algorithm when implemented correctly.
* It is useful when predictable sorting performance matters more than extra memory usage.

### 4. Main Purpose

* To sort large datasets efficiently.
* To divide a complex problem into smaller problems.
* To provide reliable `O(n log n)` sorting performance.
* It is also useful for problems such as counting inversions and sorting linked lists.
